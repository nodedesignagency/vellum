# Editing the Vellum website

You can add, reorder and hide projects, journal images and collaborator logos yourself. No code needed.

## Open the editor

1. Go to **vellum.studio/keystatic** (the live site's address followed by `/keystatic`).
2. Sign in with GitHub. Your GitHub account needs access to the website's repository; ask whoever looks after the site to add you.
3. Make your changes and press **Save**. The live site updates within a minute or two.

The editor has two areas in the left-hand menu: **Projects** and **Collaborators**.

## Projects

Each project appears twice on the site: as a card in *Selected work* on the Home page, and as a chapter in the *Project journal*.

**Add a project:** Projects, then **Add**. Fill in:

| Field | What to write |
| --- | --- |
| Title | As it should appear, e.g. *Harbour Hotel lobby*. |
| Web address | Filled in for you from the title. Avoid changing it once the project is live, or old links to it stop working. |
| Hidden | Tick to take it off the site without deleting it. |
| Order | Lower numbers show first. Use gaps (10, 20, 30) so you can slot projects in later. |
| Sector | Choose from the list. The Home page filter is built from these. |
| Location | Short and specific: *Coastal hotel, 120 keys*. |
| Year | Four digits: *2025*. |
| Summary | Two or three short sentences for the journal. |
| Cover image | The card image on the Home page. Upright (4:5) works best. |
| Cover image description | What the image shows, for people who use screen readers. |
| Journal images | The drawings and photos for the journal (see below). |

**Journal images:** press **Add** under *Journal images*. For each one choose *Drawing* or *Installation photo*, upload the image, describe it, and add a caption.

- Put the **drawings first**, then the installation photos. Drag the handle (⠿) on the left of each image to reorder.
- Tick **Hide this image** to keep an image without showing it.
- Captions follow the label style: fitting reference, colour temperature, dim level. For example: `G01 linear graze · 2700K · 40%`.

**Reorder projects:** change the *Order* numbers.

In the journal, a project's drawings always come before its installation photos, whatever order they are in here. A project with no journal images shows its cover image instead.

**Remove a project for good:** open it and use the bin icon at the top. If you might want it back, tick *Hidden* instead.

## Collaborators (the logo ticker)

Collaborators is a single list. Drag the handle (⠿) to reorder; the order on the list is the order on the page.

- **Add:** press **Add**, type the studio's name and upload its logo. SVG is best, PNG is fine. Logos are shown in grey automatically.
- **No logo yet?** Leave the logo empty and the name is shown as text instead.
- **Hide:** tick *Hide from the ticker*.

The ten collaborators on the site today are **invented placeholders**. Replace them with studios Vellum has worked with before launch.

## Images

- Upload the largest original you have. Photos at least 2000px wide. The site makes the smaller, faster versions for phones and screens automatically.
- JPG for photos and drawings, SVG or PNG for logos.
- Always fill in the description. It is what blind and partially sighted visitors hear instead of the image.

## Writing

- Plain, specific and calm. Real units: 2700K, 24°, UGR<16.
- No superlatives (*stunning*, *breathtaking*, *elevate*).
- No em dashes. Use a full stop or a comma instead.
